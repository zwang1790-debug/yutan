# YuTan Radar

YuTan Radar is a Windows desktop market intelligence and sourcing assistant for Goofish (闲鱼). The packaged installer is ready to use and helps sellers monitor selected categories, review price signals, and identify listings worth checking.

## Who It Is For

- Sellers of used electronics, GPUs, phones, cameras, lenses, and game consoles
- Individual sellers, recyclers, and small studios with repeat sourcing criteria
- Operators who want to reduce repetitive searching and notice new listings sooner

## Core Capabilities

- Multi-task monitoring by keyword, price, listing age, and region
- AI-assisted review of product details, images, seller signals, and risks
- Price references, historical position, and opportunity signals
- Result filtering, history, export, and runtime records
- Notifications through WeCom, Telegram, Bark, ntfy, and Webhook
- Local Windows storage for data, login state, and history

## Windows Customer Start

Regular users do not need Docker, Python, Node.js, or Playwright.

1. Contact business WeChat **wgviptop** with your category and Windows version to receive the latest installer or a 7-day trial.
2. Download `YuTanRadar-Setup-version.exe` from [Releases](https://github.com/zwang1790-debug/yutan/releases).
3. Install and launch YuTan Radar, then open the local management page in your browser.
4. Create the first administrator account, save the recovery code, and import your Goofish login state.
5. Create a low-frequency test task and confirm that the results fit your category.
6. After purchase, copy the device fingerprint from “Device Authorization”, send it to the seller, and paste the returned activation code.

## Important Notes

- Current licensing is for one Windows device; device changes and exceptions are handled manually.
- LLM API, proxy, and third-party notification costs are paid by the user.
- Annual plans include 12 months of updates and basic troubleshooting.
- This is a market intelligence and decision-support tool. It does not promise guaranteed deals, automated sales, or profit.
- Follow Goofish rules and applicable laws, and keep request frequency reasonable.
- Import your own Goofish login state locally and never send it to other people.

## Privacy and Security

Login state, tasks, results, logs, and configuration are stored in the local Windows data directory by default. Users provide their own AI API key; the seller's license private key is never included in the installer.
